# 📊 HR Analytics Dashboard | Power BI

Interactive HR Analytics Dashboard built using **Power BI** to analyze employee attrition, demographics, salary, departments, job roles, and experience.

## 🛠️ Tools Used
- Power BI
- DAX
- Power Query
- Data Visualization

## 📌 Key KPIs
- Total Employees: 1,417
- Active Employees: 1,186
- Attrition: 231
- Attrition Rate: 16.30%
- Average Age: 36.94
- Average Experience: 7.04 Years

## 📈 Analysis
- Attrition by Department
- Attrition by Salary
- Attrition by Gender
- Age & Experience Analysis
- Job Role & Job Satisfaction
